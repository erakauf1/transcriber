# Native iOS App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A native SwiftUI version of the Transcriber PWA (record → transcribe → clean up → refine → copy) with auto-copy, share, and an encrypted, Face ID–locked history with JSON export, shipped to internal TestFlight.

**Architecture:**
- All platform-independent logic lives in a local Swift package, `ios/TranscriberCore`: prompts, API clients, the reducer, language detection, pricing, the silence detector, the note cipher and the export encoder. It is tested with Swift Testing on macOS.
- A thin SwiftUI app target, `ios/Transcriber`, holds the recorder, Keychain, SwiftData history, Face ID lock and views.
- The Xcode project is generated by XcodeGen from `ios/project.yml`.
- Prompt parity with the web app is enforced mechanically. A Node script captures the exact prompts the JS sends into `fixtures/prompts.json`, and both a Vitest test and the Swift tests check against it.

**Tech Stack:** Swift 6, SwiftUI, SwiftData, CryptoKit, AVFoundation, LocalAuthentication, Security (Keychain), Swift Testing, XcodeGen, Node/Vitest (for the prompt fixture).

**Spec:** `docs/superpowers/specs/2026-11-21-ios-native-app-design.md`

## Global Constraints

- iOS 26 minimum. The package also declares macOS 26 so `swift test` runs on the Mac.
- Swift 6 language mode (strict concurrency). Core types are `Sendable`.
- Internal TestFlight only. Every user enters their own API keys.
- Not in v1: learned fixes, noise suppression of any kind, Shortcuts and App Intents, keyboard, iCloud.
- Transcription: `gpt-4o-transcribe`, no `language` param, prompt is the script hint only, 120 s timeout, file field named `note.m4a`.
- Prompts are copied verbatim from `src/cleanup.js`, `src/refine.js` and `src/englishTerms.js`. `fixtures/prompts.json` is the arbiter.
- Default providers: Cleanup = `anthropic`, Refine = `openai`. Default models: OpenAI `gpt-4o`, Anthropic `claude-sonnet-5`, OpenRouter `openrouter/auto`.
- Recording: AAC `.m4a`, mono, 44.1 kHz, max 300 s.
- API keys and the history key: Keychain, `kSecAttrAccessibleWhenUnlockedThisDeviceOnly`.
- History store: `FileProtectionType.complete`, excluded from backup. `rawTranscript` and `cleanedText` are AES-GCM ciphertext.
- Pending audio files: `FileProtectionType.completeUnlessOpen`, excluded from backup. This keeps a recording writable after the phone locks.
- History unlock: `.deviceOwnerAuthentication`, which re-locks after more than 60 s in the background or when History closes.
- Export: plain JSON array, oldest first. Keys are `name`, `text`, `cleaned` (always present, may be `null`), `language`, `date`, `provider` and `model`.
- Code comments: sparing. Only for a non-obvious why.

```js
// The iOS app copies these prompts verbatim; this file is what it is checked against.
import { writeFileSync } from 'node:fs';
import { fileURLToPath } from 'node:url';
import { cleanup } from '../src/cleanup.js';
import { findEnglishTerms } from '../src/englishTerms.js';
import { generateRefinementChips, applyRefinement } from '../src/refine.js';

const TEXT = 'TEXT';
const INSTRUCTION = 'Make shorter';
const STEP = { provider: 'anthropic', model: 'claude-sonnet-5', apiKey: 'k' };
const REPLY = '{"chips":[{"label":"a","instruction":"b"}],"terms":[]}';

export async function buildPromptFixture() {
  const realFetch = globalThis.fetch;
  let body;
  globalThis.fetch = async (_url, opts) => {
    body = JSON.parse(opts.body);
    return { ok: true, json: async () => ({ content: [{ type: 'text', text: REPLY }] }) };
  };
  const capture = async (fn) => { await fn(); return { system: body.system, messages: body.messages }; };
  try {
    const out = { text: TEXT, instruction: INSTRUCTION, cleanup: {}, refineChips: {}, refineApply: {} };
    for (const lang of ['he', 'en']) {
      out.cleanup[lang] = await capture(() => cleanup(TEXT, lang, STEP));
      out.refineChips[lang] = await capture(() => generateRefinementChips(TEXT, lang, STEP));
      out.refineApply[lang] = await capture(() => applyRefinement(TEXT, lang, INSTRUCTION, STEP));
    }
    out.englishTerms = await capture(() => findEnglishTerms(TEXT, STEP));
    return out;
  } finally {
    globalThis.fetch = realFetch;
  }
}

if (process.argv[1] === fileURLToPath(import.meta.url)) {
  const out = await buildPromptFixture();
  writeFileSync(new URL('../fixtures/prompts.json', import.meta.url), JSON.stringify(out, null, 2) + '\n');
}
```

```swift
public enum Language: String, Codable, Sendable, CaseIterable {
    case he, en

    public var displayName: String { self == .he ? "Hebrew" : "English" }
}

public func detectLanguage(_ text: String) -> Language {
    var hebrew = 0, latin = 0
    for scalar in text.unicodeScalars {
        switch scalar.value {
        case 0x0590...0x05FF: hebrew += 1
        case 0x41...0x5A, 0x61...0x7A: latin += 1
        default: break
        }
    }
    return hebrew > latin ? .he : .en
}
```

- [ ] **Step 3: Implement** `State.swift`:

```swift
import Foundation

public enum Phase: Equatable, Sendable {
    case idle, recording, transcribing, cleaning, result, interrupted
}

public struct AppState: Equatable, Sendable {
    public var phase: Phase = .idle
    public var audioFile: URL?
    public var rawTranscript: String?
    public var language: Language?
    public var cleanedText: String?
    public var error: String?
    public var autoCopied = false

    public init() {}
}

public enum AppEvent: Sendable {
    case recordStart
    case recordStop(URL)
    case recordInterrupted(URL)
    case interruptedTranscribe
    case transcribeOK(text: String, language: Language)
    case transcribeFail(String)
    case transcribeRetry
    case cleanupOK(text: String, autoCopied: Bool)
    case cleanupFail(message: String, autoCopied: Bool)
    case cleanupRetry
    case refineOK(String)
    case editCommit(String)
    case reset
}

public func reduce(_ state: AppState, _ event: AppEvent) -> AppState {
    var s = state
    switch event {
    case .recordStart:
        s = AppState(); s.phase = .recording
    case .recordStop(let url):
        s.phase = .transcribing; s.audioFile = url; s.error = nil
    case .recordInterrupted(let url):
        s.phase = .interrupted; s.audioFile = url
    case .interruptedTranscribe:
        s.phase = .transcribing; s.error = nil
    case .transcribeOK(let text, let language):
        // Audio is released only now: a failed transcription must stay retryable.
        s.phase = .cleaning; s.rawTranscript = text; s.language = language; s.audioFile = nil; s.error = nil
    case .transcribeFail(let message):
        s.error = message
    case .transcribeRetry:
        s.error = nil
    case .cleanupOK(let text, let autoCopied):
        s.phase = .result; s.cleanedText = text; s.error = nil; s.autoCopied = autoCopied
    case .cleanupFail(let message, let autoCopied):
        s.phase = .result; s.cleanedText = nil; s.error = message; s.autoCopied = autoCopied
    case .cleanupRetry:
        s.phase = .cleaning; s.error = nil; s.autoCopied = false
    case .refineOK(let text):
        s.cleanedText = text
    case .editCommit(let text):
        guard s.phase == .result, !text.trimmingCharacters(in: .whitespacesAndNewlines).isEmpty else { return state }
        // After a failed cleanup the editor shows the raw transcript, so that is what was edited.
        if s.cleanedText != nil { s.cleanedText = text } else { s.rawTranscript = text }
    case .reset:
        s = AppState()
    }
    return s
}
```

```swift
struct StubRequest: Sendable {
    let url: URL
    let headers: [String: String]
    let body: Data
    var json: [String: Any] { (try? JSONSerialization.jsonObject(with: body)) as? [String: Any] ?? [:] }

typealias StubHandler = @Sendable (StubRequest) -> (status: Int, body: Data)

/// Each session gets its own handler, keyed by a header, so parallel tests don't collide.
final class StubURLProtocol: URLProtocol {
    private static let handlers = Mutex<[String: StubHandler]>([:])
    private static let idHeader = "X-Stub-ID"

    static func session(_ handler: @escaping StubHandler) -> URLSession {
        let id = UUID().uuidString
        handlers.withLock { $0[id] = handler }
        let config = URLSessionConfiguration.ephemeral
        config.protocolClasses = [StubURLProtocol.self]
        config.httpAdditionalHeaders = [idHeader: id]
        return URLSession(configuration: config)
    }

    static func json(_ object: Any, status: Int = 200) -> (status: Int, body: Data) {
        (status, try! JSONSerialization.data(withJSONObject: object))
    }

    override class func canInit(with request: URLRequest) -> Bool { true }
    override class func canonicalRequest(for request: URLRequest) -> URLRequest { request }
    override func stopLoading() {}

    override func startLoading() {
        let headers = request.allHTTPHeaderFields ?? [:]
        guard let id = headers[Self.idHeader], let handler = Self.handlers.withLock({ $0[id] }) else {
            client?.urlProtocol(self, didFailWithError: URLError(.unsupportedURL)); return
        }
        let reply = handler(StubRequest(url: request.url!, headers: headers, body: Self.body(of: request)))
        let response = HTTPURLResponse(url: request.url!, statusCode: reply.status, httpVersion: nil, headerFields: nil)!
        client?.urlProtocol(self, didReceive: response, cacheStoragePolicy: .notAllowed)
        client?.urlProtocol(self, didLoad: reply.body)
        client?.urlProtocolDidFinishLoading(self)
    }

    private static func body(of request: URLRequest) -> Data {
        if let body = request.httpBody { return body }
        guard let stream = request.httpBodyStream else { return Data() }
        stream.open(); defer { stream.close() }
        var data = Data()
        var buffer = [UInt8](repeating: 0, count: 4096)
        while stream.hasBytesAvailable {
            let n = stream.read(&buffer, maxLength: buffer.count)
            if n <= 0 { break }
            data.append(buffer, count: n)
        }
        return data
    }
}
```

```swift
import Foundation

public struct ChatMessage: Codable, Equatable, Sendable {
    public var role: String
    public var content: String
    public init(role: String, content: String) { self.role = role; self.content = content }
}

public struct ChatRequest: Sendable {
    public var provider: Provider
    public var model: String
    public var apiKey: String
    public var systemPrompt: String
    public var messages: [ChatMessage]
    public var temperature: Double?
    public var maxTokens: Int
    public var jsonMode: Bool
    public var timeout: TimeInterval

    public init(provider: Provider, model: String, apiKey: String, systemPrompt: String, messages: [ChatMessage],
                temperature: Double? = nil, maxTokens: Int, jsonMode: Bool = false, timeout: TimeInterval = 60) {
        self.provider = provider; self.model = model; self.apiKey = apiKey; self.systemPrompt = systemPrompt
        self.messages = messages; self.temperature = temperature; self.maxTokens = maxTokens
        self.jsonMode = jsonMode; self.timeout = timeout
    }
}

public struct Usage: Equatable, Sendable {
    public let provider: Provider
    public let model: String
    public let inputTokens: Int
    public let outputTokens: Int
    public let costUsd: Double?
}

public typealias UsageHandler = @Sendable (Usage) -> Void

public struct LLMClient: Sendable {
    static let anthropicURL = URL(string: "https://api.anthropic.com/v1/messages")!
    static let openAIURL = URL(string: "https://api.openai.com/v1/chat/completions")!
    static let openRouterURL = URL(string: "https://openrouter.ai/api/v1/chat/completions")!

    let session: URLSession

    public init(session: URLSession = .shared) { self.session = session }

    public func send(_ r: ChatRequest, onUsage: UsageHandler? = nil) async throws -> String {
        r.provider == .anthropic ? try await anthropic(r, onUsage) : try await openAICompatible(r, onUsage)
    }

    // Newer Claude models reject `thinking: disabled` with a 400, so each gets the closest
    // low-thinking setting it accepts, plus output headroom when it always thinks.
    static func anthropicThinkingParams(model: String, maxTokens: Int) -> [String: Any] {
        if model == "claude-sonnet-5-5" { return ["thinking": ["type": "between_tools"], "max_tokens": maxTokens] }
        if model == "claude-opus-5-5" || model.hasPrefix("claude-fable-") {
            return ["output_config": ["effort": "low"], "max_tokens": max(maxTokens, 16000)]
        }
        return ["thinking": ["type": "disabled"], "max_tokens": maxTokens]
    }

    private func anthropic(_ r: ChatRequest, _ onUsage: UsageHandler?) async throws -> String {
        var body: [String: Any] = [
            "model": r.model,
            "system": r.systemPrompt,
            "messages": r.messages.map { ["role": $0.role, "content": $0.content] },
        ]
        body.merge(Self.anthropicThinkingParams(model: r.model, maxTokens: r.maxTokens)) { _, new in new }
        let data = try await post(Self.anthropicURL, body: body, timeout: r.timeout, headers: [
            "x-api-key": r.apiKey,
            "anthropic-version": "2023-06-01",
        ])
        let usage = data["usage"] as? [String: Any]
        report(onUsage, r, input: usage?["input_tokens"] as? Int, output: usage?["output_tokens"] as? Int, reported: nil)
        if data["stop_reason"] as? String == "refusal" {
            throw ServiceError("The model declined this request — try again or pick another model")
        }
        let blocks = data["content"] as? [[String: Any]] ?? []
        let text = (blocks.first { $0["type"] as? String == "text" }?["text"] as? String ?? "")
            .trimmingCharacters(in: .whitespacesAndNewlines)
        guard !text.isEmpty else { throw ServiceError("Empty response") }
        return text
    }

    private func openAICompatible(_ r: ChatRequest, _ onUsage: UsageHandler?) async throws -> String {
        var headers = ["Authorization": "Bearer \(r.apiKey)"]
        if r.provider == .openrouter {
            headers["HTTP-Referer"] = "https://the-transcriber.netlify.app"
            headers["X-Title"] = "Voice Note Transcriber"
        }
        var body: [String: Any] = [
            "model": r.model,
            "messages": [["role": "system", "content": r.systemPrompt]] + r.messages.map { ["role": $0.role, "content": $0.content] },
        ]
        if let t = r.temperature { body["temperature"] = t }
        if r.jsonMode { body["response_format"] = ["type": "json_object"] }
        let url = r.provider == .openrouter ? Self.openRouterURL : Self.openAIURL
        let data = try await post(url, body: body, timeout: r.timeout, headers: headers)
        let usage = data["usage"] as? [String: Any]
        report(onUsage, r, input: usage?["prompt_tokens"] as? Int, output: usage?["completion_tokens"] as? Int,
               reported: usage?["cost"] as? Double)
        let choices = data["choices"] as? [[String: Any]]
        let message = choices?.first?["message"] as? [String: Any]
        let text = (message?["content"] as? String ?? "").trimmingCharacters(in: .whitespacesAndNewlines)
        guard !text.isEmpty else { throw ServiceError("Empty response") }
        return text
    }

    private func report(_ onUsage: UsageHandler?, _ r: ChatRequest, input: Int?, output: Int?, reported: Double?) {
        guard let onUsage else { return }
        let i = input ?? 0, o = output ?? 0
        onUsage(Usage(provider: r.provider, model: r.model, inputTokens: i, outputTokens: o,
                      costUsd: Pricing.estimateCost(model: r.model, inputTokens: i, outputTokens: o, reportedCost: reported)))
    }

    private func post(_ url: URL, body: [String: Any], timeout: TimeInterval, headers: [String: String]) async throws -> [String: Any] {
        var req = URLRequest(url: url, timeoutInterval: timeout)
        req.httpMethod = "POST"
        req.setValue("application/json", forHTTPHeaderField: "Content-Type")
        for (k, v) in headers { req.setValue(v, forHTTPHeaderField: k) }
        req.httpBody = try JSONSerialization.data(withJSONObject: body)
        let (data, response): (Data, URLResponse)
        do { (data, response) = try await session.data(for: req) }
        catch { throw ServiceError("Network error: \(error.localizedDescription)") }
        let status = (response as? HTTPURLResponse)?.statusCode ?? 0
        let json = (try? JSONSerialization.jsonObject(with: data)) as? [String: Any]
        guard (200..<300).contains(status) else {
            if let detail = (json?["error"] as? [String: Any])?["message"] as? String {
                throw ServiceError("Request failed: \(detail)")
            }
            throw ServiceError("Request failed (HTTP \(status))")
        }
        return json ?? [:]
    }
}
```

```swift
import Foundation

public struct Transcriber: Sendable {
    public static let model = "gpt-4o-transcribe"
    public static let scriptHint =
        "This recording may mix languages. Write every word in its original script: " +
        "keep English words such as deploy, follow-up, meeting, standup, and sprint in Latin letters, " +
        "and keep Hebrew words in Hebrew letters. Do not transliterate between scripts."
    static let url = URL(string: "https://api.openai.com/v1/audio/transcriptions")!

    let session: URLSession

    public init(session: URLSession = .shared) { self.session = session }

    public func transcribe(fileURL: URL, apiKey: String) async throws -> String {
        let boundary = "Boundary-\(UUID().uuidString)"
        var body = Data()
        func field(_ name: String, _ value: String) {
            body.append(Data("--\(boundary)\r\nContent-Disposition: form-data; name=\"\(name)\"\r\n\r\n\(value)\r\n".utf8))
        }
        body.append(Data("--\(boundary)\r\nContent-Disposition: form-data; name=\"file\"; filename=\"note.m4a\"\r\nContent-Type: audio/mp4\r\n\r\n".utf8))
        body.append(try Data(contentsOf: fileURL))
        body.append(Data("\r\n".utf8))
        field("model", Self.model)
        // No `language` field: auto-detect keeps code-switched words in their original script.
        field("prompt", Self.scriptHint)
        body.append(Data("--\(boundary)--\r\n".utf8))

        var req = URLRequest(url: Self.url, timeoutInterval: 120)
        req.httpMethod = "POST"
        req.setValue("Bearer \(apiKey)", forHTTPHeaderField: "Authorization")
        req.setValue("multipart/form-data; boundary=\(boundary)", forHTTPHeaderField: "Content-Type")
        req.httpBody = body

        let (data, response): (Data, URLResponse)
        do { (data, response) = try await session.data(for: req) }
        catch { throw ServiceError("Network error: \(error.localizedDescription)") }
        let status = (response as? HTTPURLResponse)?.statusCode ?? 0
        guard (200..<300).contains(status) else { throw ServiceError("Transcription failed (HTTP \(status))") }
        let json = (try? JSONSerialization.jsonObject(with: data)) as? [String: Any]
        let text = (json?["text"] as? String ?? "").trimmingCharacters(in: .whitespacesAndNewlines)
        guard !text.isEmpty else { throw ServiceError("Transcription returned empty text") }
```

```swift
import Foundation

public struct EnglishTerm: Codable, Equatable, Sendable {
    public let he: String
    public let en: String
    public init(he: String, en: String) { self.he = he; self.en = en }
}

/// The model only proposes Hebrew→English pairs; code applies a pair only when the
/// replacement is Latin, so a Hebrew name can never become a different Hebrew name.
public enum EnglishTerms {
    public static let systemPrompt = [
        #"You read a Hebrew voice-note transcript. The speech-to-text step sometimes writes English words that the speaker said in English using Hebrew letters — job titles, tech and business terms, acronyms."#,
        #"Find those words and give their English spelling, judging from the context of the whole message."#,
        "",
        #"Include only terms an Israeli would naturally type in English in a work chat — e.g. VP, CTO, engineering, product, deploy, staging, sprint, backend, dashboard, follow-up."#,
        #"Do not include:"#,
        #"- Names of people, places, companies, or products — leave every name in Hebrew, even a foreign one"#,
        #"- Loanwords that are normally written in Hebrew letters (טלפון, מחשב, אינטרנט, מייל, אוטו)"#,
        #"- Ordinary Hebrew words, even if they could also be read as a transliteration"#,
        #"When unsure, leave the word out."#,
        "",
        #"Return a JSON object in this exact shape: {"terms": [{"he": "...", "en": "..."}]}"#,
        #"- "he" is the word or phrase exactly as it appears in the transcript, without attached Hebrew prefix letters (ב ל ה ו כ מ ש): for "לסטייג'ינג" give "סטייג'ינג""#,
        #"- A multi-word term goes in one entry: {"he": "ויפי סיילס", "en": "VP sales"}"#,
        #"- "en" is written only in Latin letters, lowercase except acronyms and proper capitalization (VP, CTO, QA, API)"#,
        #"- If there are none, return {"terms": []}"#,
    ].joined(separator: "\n")

    static let latinTerm = try! NSRegularExpression(pattern: #"^[A-Za-z0-9](?:[A-Za-z0-9 .&'/+-]*[A-Za-z0-9.+])?$"#)
    static let hebrewChar = try! NSRegularExpression(pattern: "[\(Hebrew.rangePattern)]")

    public static func request(text: String, step: StepConfig) -> ChatRequest {
        ChatRequest(provider: step.provider, model: step.model, apiKey: step.apiKey, systemPrompt: systemPrompt,
                    messages: [ChatMessage(role: "user", content: text)],
                    temperature: 0, maxTokens: 1024, jsonMode: true, timeout: 30)
    }

    /// Anthropic has no JSON mode, so tolerate a fenced or prefaced reply.
    public static func parse(_ content: String) throws -> [EnglishTerm] {
        guard let start = content.firstIndex(of: "{"), let end = content.lastIndex(of: "}"), start < end else {
            throw ServiceError("Could not parse terms")
        }
        struct Reply: Decodable { let terms: [EnglishTerm]? }
        return try JSONDecoder().decode(Reply.self, from: Data(content[start...end].utf8)).terms ?? []
    }

    public static func apply(_ text: String, terms: [EnglishTerm]) -> String {
        func matches(_ re: NSRegularExpression, _ s: String) -> Bool {
            re.firstMatch(in: s, range: NSRange(s.startIndex..., in: s)) != nil
        }
        let valid = terms
            .map { EnglishTerm(he: $0.he.trimmingCharacters(in: .whitespaces), en: $0.en.trimmingCharacters(in: .whitespaces)) }
            .filter { matches(hebrewChar, $0.he) && matches(latinTerm, $0.en) }
            .sorted { $0.he.count > $1.he.count }

        var out = text
        for term in valid {
            let pattern = "(^|[^\(Hebrew.rangePattern)])([\(Hebrew.prefixes)]{0,2})"
                + NSRegularExpression.escapedPattern(for: term.he)
                + "(?![\(Hebrew.rangePattern)])"
            guard let re = try? NSRegularExpression(pattern: pattern) else { continue }
            out = re.stringByReplacingMatches(in: out, range: NSRange(out.startIndex..., in: out),
                                              withTemplate: "$1$2" + NSRegularExpression.escapedTemplate(for: term.en))
        }
        return out
    }

    public static func restore(text: String, language: Language, step: StepConfig, client: LLMClient,
                               onUsage: UsageHandler? = nil) async -> String {
        guard language == .he, !step.apiKey.isEmpty else { return text }
        do {
            let content = try await client.send(request(text: text, step: step), onUsage: onUsage)
            return apply(text, terms: try parse(content))
        } catch {
            return text
        }
    }
}
```

```swift
import Foundation

public struct RefineChip: Identifiable, Equatable, Sendable {
    public var id: String { label + "\u{0}" + instruction }
    public let label: String
    public let instruction: String
    public init(label: String, instruction: String) { self.label = label; self.instruction = instruction }
}

public enum Refine {
    public static func chipsRequest(text: String, language: Language, step: StepConfig) -> ChatRequest {
        let lang = language.displayName
        let system = [
            #"You suggest specific, useful one-tap refinement actions for a cleaned-up voice note message."#,
            #"The message is in \#(lang). Suggest 3–4 short actions that would genuinely improve THIS specific message."#,
            #"Return a JSON object in this exact shape: {"chips": [{"label": "...", "instruction": "..."}, ...]}"#,
            #"Rules:"#,
            #"- "label" is 2–4 words max, written in \#(lang) (so the user sees it in their language)"#,
            #"- "instruction" is always in English — it is the prompt used to transform the message"#,
            #"- Options must be specific to this content, not generic filler"#,
            #"- Do not suggest formatting already present in the message (e.g. don't suggest bullet points if they're already there)"#,
            #"- Examples of good labels: "Make shorter", "More formal", "Add details", "Softer tone", "Clearer request""#,
        ].joined(separator: "\n")
        return ChatRequest(provider: step.provider, model: step.model, apiKey: step.apiKey, systemPrompt: system,
                           messages: [ChatMessage(role: "user", content: text)],
                           temperature: 0.7, maxTokens: 1024, jsonMode: true, timeout: 30)
    }

    public static func parseChips(_ content: String) throws -> [RefineChip] {
        guard let parsed = try? JSONSerialization.jsonObject(with: Data(content.utf8)) else {
            throw ServiceError("Could not parse suggestions")
        }
        let dict = parsed as? [String: Any]
        let array = (parsed as? [Any]) ?? (dict?["chips"] as? [Any]) ?? (dict?["options"] as? [Any])
        guard let array, !array.isEmpty else { throw ServiceError("No valid suggestions returned") }
        return array.prefix(4).compactMap { item in
            guard let c = item as? [String: Any], let label = c["label"], let instruction = c["instruction"] else { return nil }
            let l = "\(label)".trimmingCharacters(in: .whitespacesAndNewlines)
            let i = "\(instruction)".trimmingCharacters(in: .whitespacesAndNewlines)
            return l.isEmpty || i.isEmpty ? nil : RefineChip(label: l, instruction: i)
        }
    }

    public static func chips(text: String, language: Language, step: StepConfig, client: LLMClient,
                             onUsage: UsageHandler? = nil) async throws -> [RefineChip] {
        let content: String
        do { content = try await client.send(chipsRequest(text: text, language: language, step: step), onUsage: onUsage) }
        catch let e as ServiceError {
            throw e.replacingPrefix("Request failed", with: "Could not generate suggestions")
                .replacingPrefix("Empty response", with: "No suggestions returned")
        }
        return try parseChips(content)
    }

    public static func applyRequest(text: String, language: Language, instruction: String, step: StepConfig) -> ChatRequest {
        let lang = language.displayName
        let system = [
            #"You refine voice-note messages by applying a specific transformation."#,
            #"The message is in \#(lang). Never translate anything — preserve the language throughout."#,
            #"Keep the personal tone and meaning unless the instruction explicitly asks to change it."#,
            #"Output only the refined message. No preamble, no quotes, no explanations."#,
        ].joined(separator: "\n")
        return ChatRequest(provider: step.provider, model: step.model, apiKey: step.apiKey, systemPrompt: system,
                           messages: [ChatMessage(role: "user", content: "\(instruction):\n\n\(text)")],
                           temperature: 0, maxTokens: 4096, timeout: 60)
    }
```

```swift
import Foundation

public enum VADEvent: Equatable, Sendable { case speechStart, speechEnd }

public struct SilenceDetector: Sendable {
    public let threshold: Double
    public let silence: TimeInterval
    public private(set) var speaking = false
    private var aboveCount = 0
    private var silenceSince: Date?

    public init(threshold: Double = 0.05, silence: TimeInterval = 0.8) {
        self.threshold = threshold; self.silence = silence
    }

    public mutating func update(peak: Double, now: Date) -> VADEvent? {
        if peak >= threshold {
            silenceSince = nil
            aboveCount += 1
            if !speaking && aboveCount >= 2 { speaking = true; return .speechStart }
            return nil
        }
        aboveCount = 0
        guard speaking else { return nil }
        guard let since = silenceSince else { silenceSince = now; return nil }
        if now.timeIntervalSince(since) >= silence {
            speaking = false; silenceSince = nil
            return .speechEnd
        }
        return nil
    }
}
```

```swift
import CryptoKit

public struct NoteCipher: Sendable {
    public struct Unreadable: Error {}

    private let key: SymmetricKey

    public init(key: SymmetricKey) { self.key = key }

    public func seal(_ text: String) throws -> Data {
        try AES.GCM.seal(Data(text.utf8), using: key).combined!
    }

    public func open(_ data: Data) throws -> String {
        do {
            let plain = try AES.GCM.open(AES.GCM.SealedBox(combined: data), using: key)
            guard let text = String(data: plain, encoding: .utf8) else { throw Unreadable() }
            return text
        } catch {
            throw Unreadable()
        }
    }
}
```

```swift
import Foundation

public struct ExportEntry: Encodable, Sendable {
    public let date: Date
    public let text: String
    public let cleaned: String?
    public let language: Language?
    public let provider: Provider?
    public let model: String?

    public init(date: Date, text: String, cleaned: String?, language: Language?, provider: Provider?, model: String?) {
        self.date = date; self.text = text; self.cleaned = cleaned
        self.language = language; self.provider = provider; self.model = model
    }

    enum CodingKeys: String, CodingKey { case name, text, cleaned, language, date, provider, model }

    // Explicit so `cleaned` is written as null rather than omitted.
    public func encode(to encoder: Encoder) throws {
        // ISO8601FormatStyle is Sendable; a static DateFormatter fails Swift 6 strict concurrency.
        let iso = date.formatted(.iso8601)
        var c = encoder.container(keyedBy: CodingKeys.self)
        try c.encode(String(iso.dropLast()).replacingOccurrences(of: ":", with: "-"), forKey: .name)
        try c.encode(text, forKey: .text)
        try c.encode(cleaned, forKey: .cleaned)
        try c.encode(language, forKey: .language)
        try c.encode(iso, forKey: .date)
        try c.encode(provider, forKey: .provider)
        try c.encode(model, forKey: .model)
    }
}

public enum HistoryExport {
    public static func encode(_ entries: [ExportEntry]) throws -> Data {
        let encoder = JSONEncoder()
        encoder.outputFormatting = [.prettyPrinted, .withoutEscapingSlashes]
        return try encoder.encode(entries.sorted { $0.date < $1.date })
    }
}
```

```swift
import Foundation
import Security

enum KeychainRead { case found(Data), notFound, unavailable }

enum Keychain {
    static let service = "transcriber"

    private static func base(_ account: String) -> [String: Any] {
        [kSecClass as String: kSecClassGenericPassword,
         kSecAttrService as String: service,
         kSecAttrAccount as String: account]
    }

    static func read(_ account: String) -> KeychainRead {
        var query = base(account)
        query[kSecReturnData as String] = true
        query[kSecMatchLimit as String] = kSecMatchLimitOne
        var out: CFTypeRef?
        switch SecItemCopyMatching(query as CFDictionary, &out) {
        case errSecSuccess: return (out as? Data).map(KeychainRead.found) ?? .notFound
        case errSecItemNotFound: return .notFound
        default: return .unavailable  // e.g. errSecInteractionNotAllowed while the phone is locked
        }
    }

    @discardableResult
    static func set(_ data: Data?, for account: String) -> Bool {
        SecItemDelete(base(account) as CFDictionary)
        guard let data else { return true }
        var add = base(account)
        add[kSecValueData as String] = data
        add[kSecAttrAccessible as String] = kSecAttrAccessibleWhenUnlockedThisDeviceOnly
        return SecItemAdd(add as CFDictionary, nil) == errSecSuccess
    }

    static func string(for account: String) -> String? {
        if case .found(let d) = read(account) { return String(data: d, encoding: .utf8) }
        return nil
    }

    static func setString(_ value: String, for account: String) {
        let trimmed = value.trimmingCharacters(in: .whitespacesAndNewlines)
        set(trimmed.isEmpty ? nil : Data(trimmed.utf8), for: account)
    }
}
```

```swift
@MainActor
final class Recorder: NSObject, AVAudioRecorderDelegate {
    enum FinishReason { case user, cap, interrupted }
    struct StartError: LocalizedError { var errorDescription: String? { "Could not start recording" } }

    static let maxDuration: TimeInterval = 300

    var onTick: (TimeInterval) -> Void = { _ in }
    var onLevel: (Double) -> Void = { _ in }
    var onVAD: (VADEvent) -> Void = { _ in }
    var onFinish: (URL, FinishReason) -> Void = { _, _ in }

    private var recorder: AVAudioRecorder?
    private var meterTimer: Timer?
    private var detector = SilenceDetector()
    private var interruptionObserver: NSObjectProtocol?

    var isRecording: Bool { recorder != nil }

    static func requestPermission() async -> Bool { await AVAudioApplication.requestRecordPermission() }

    func start() throws {
        guard recorder == nil else { throw StartError() }
        let session = AVAudioSession.sharedInstance()
        try session.setCategory(.record, mode: .default)
        try session.setActive(true)
        let settings: [String: Any] = [
            AVFormatIDKey: kAudioFormatMPEG4AAC,
            AVSampleRateKey: 44_100,
            AVNumberOfChannelsKey: 1,
            AVEncoderAudioQualityKey: AVAudioQuality.high.rawValue,

        let r = try AVAudioRecorder(url: try AudioFiles.newURL(), settings: settings)
        r.delegate = self
        r.isMeteringEnabled = true
        guard r.record(forDuration: Self.maxDuration) else { throw StartError() }
        recorder = r
        detector = SilenceDetector()
        meterTimer = Timer.scheduledTimer(withTimeInterval: 1.0 / 30, repeats: true) { [weak self] _ in
            MainActor.assumeIsolated { self?.meterTick() }
        }
        interruptionObserver = NotificationCenter.default.addObserver(
            forName: AVAudioSession.interruptionNotification, object: session, queue: .main) { [weak self] note in
            let raw = note.userInfo?[AVAudioSessionInterruptionTypeKey] as? UInt
            guard raw == AVAudioSession.InterruptionType.began.rawValue else { return }
            MainActor.assumeIsolated { self?.finish(.interrupted) }
        }
    }

    func stop() { finish(.user) }

    private func meterTick() {
        guard let r = recorder else { return }
        r.updateMeters()
        let peak = pow(10, Double(r.peakPower(forChannel: 0)) / 20)
        onLevel(peak)
        onTick(r.currentTime)
        if let event = detector.update(peak: peak, now: .now) { onVAD(event) }
    }

    private func finish(_ reason: FinishReason) {
        guard let r = recorder else { return }
        recorder = nil
        meterTimer?.invalidate(); meterTimer = nil
        if let o = interruptionObserver { NotificationCenter.default.removeObserver(o); interruptionObserver = nil }
        r.stop()
        try? AVAudioSession.sharedInstance().setActive(false, options: .notifyOthersOnDeactivation)
        onFinish(r.url, reason)
    }

    // Fires for the 5:00 cap, and also after our own stop() — by then `recorder` is nil, so it's a no-op.
    nonisolated func audioRecorderDidFinishRecording(_ recorder: AVAudioRecorder, successfully flag: Bool) {
        Task { @MainActor in self.finish(.cap) }
    }
}
```

```swift
            dispatch(.recordInterrupted(url))
        } else {
            dispatch(.recordStop(url))

        dispatch(.interruptedTranscribe)
        runPipeline()
    }

    /// Re-runs a saved note whose transcription failed (from History).
    func retry(_ snapshot: NoteSnapshot) {
        guard state.phase == .idle || state.phase == .result, let file = snapshot.pendingAudioFile else { return }
        dispatch(.reset)
        beginNote(id: snapshot.id, createdAt: snapshot.createdAt)
        dispatch(.recordStop(AudioFiles.url(named: file)))
        runPipeline()

    private func beginNote(id: UUID, createdAt: Date) {
        openAIKey = settings.openAIKey
        cleanupStep = settings.cleanupStep()
        cost.reset(); costText = nil; chips = []; chipsError = nil; refineError = nil
        note = NoteSnapshot(id: id, createdAt: createdAt, status: .transcriptionFailed)

    // MARK: Pipeline

    private func runPipeline() {
        let task = BackgroundTask.begin("transcribe")
        Task {
            defer { task.end() }
            await transcribeStep()
            if state.phase == .cleaning { await cleanupStepRun() }
        }
    }

    func retryTranscription() {
        dispatch(.transcribeRetry)
        runPipeline()
    }

    func retryCleanup() {
        dispatch(.cleanupRetry)
        let task = BackgroundTask.begin("cleanup")
        Task { defer { task.end() }; await cleanupStepRun() }
    }

    private func transcribeStep() async {
        guard let url = state.audioFile else { return }
        do {
            let text = try await transcriber.transcribe(fileURL: url, apiKey: openAIKey)
            dispatch(.transcribeOK(text: text, language: detectLanguage(text)))
            try? FileManager.default.removeItem(at: url)
            note?.pendingAudioFile = nil
            note?.rawTranscript = text
            note?.language = state.language
        } catch {
            dispatch(.transcribeFail(error.localizedDescription))
            note?.status = .transcriptionFailed
            note?.pendingAudioFile = url.lastPathComponent
            saveNote()
        }
    }

    private func cleanupStepRun() async {
        guard let raw = state.rawTranscript, let lang = state.language, let step = cleanupStep else { return }
        let usage: UsageHandler = { [cost] in cost.add(.cleanup, $0.costUsd) }
        note?.provider = step.provider; note?.model = step.model
        do {
            let withTerms = await EnglishTerms.restore(text: raw, language: lang, step: step, client: client, onUsage: usage)
            let cleaned = try await Cleanup.run(text: withTerms, language: lang, step: step, client: client, onUsage: usage)
            dispatch(.cleanupOK(text: cleaned, autoCopied: autoCopy(cleaned)))
            note?.status = .done
            note?.cleanedText = cleaned
        } catch {
            dispatch(.cleanupFail(message: error.localizedDescription, autoCopied: autoCopy(raw)))
            note?.status = .cleanupFailed
        }
        updateCost()
        saveNote()
        if state.cleanedText != nil { await loadChips() }
    }

    private func saveNote() {
        guard var n = note else { return }
        n.costUsd = cost.total
        note = n
        onNoteChanged(n)
    }

    private func updateCost() { costText = cost.total.map { "Estimated cost: \(Pricing.format($0))" } }

    // MARK: Refine

    private func loadChips() async {
        let step = settings.refineStep()
        guard !step.apiKey.isEmpty, let lang = state.language, let text = state.cleanedText else { return }
        do {
            chips = try await Refine.chips(text: text, language: lang, step: step, client: client) { [cost] in cost.add(.refine, $0.costUsd) }
            chipsError = nil
        } catch {
            chipsError = error.localizedDescription
        }
        updateCost()
    }

    func applyChip(_ chip: RefineChip) async {
        let step = settings.refineStep()
        guard let lang = state.language, !isRefining else { return }
        isRefining = true; refineError = nil
        defer { isRefining = false }
        do {
            let text = try await Refine.apply(text: currentText, language: lang, instruction: chip.instruction,
                                              step: step, client: client) { [cost] in cost.add(.refine, $0.costUsd) }
            dispatch(.refineOK(text))
            note?.cleanedText = text
            saveNote()
        } catch {
            refineError = error.localizedDescription
        }
        updateCost()
    }

    func commitEdit(_ text: String) {
        let before = state
        dispatch(.editCommit(text))
        guard state != before else { return }
        note?.cleanedText = state.cleanedText
        note?.rawTranscript = state.rawTranscript
        saveNote()
    }

    // MARK: Clipboard

    // Written immediately even in the background so it can be pasted elsewhere right away;
    // written again on return in case iOS dropped the background write (checked on device in Task 13).
    private func autoCopy(_ text: String) -> Bool {
        UIPasteboard.general.string = text
        if UIApplication.shared.applicationState == .active { showToast("Copied") } else { pendingCopy = text }
        return true
    }

    func copyCurrent() {
        UIPasteboard.general.string = currentText
        showToast("Copied")
    }

    func copy(_ text: String) {
        UIPasteboard.general.string = text
        showToast("Copied")
    }

    private func showToast(_ text: String) {
        toast = text
        Task { try? await Task.sleep(for: .seconds(2)); if toast == text { toast = nil } }

    func scenePhaseChanged(_ phase: ScenePhase) {
        if phase == .active, let text = pendingCopy {
            pendingCopy = nil
            UIPasteboard.general.string = text
            showToast("Copied")
        }
    }

    func reset() {
        dispatch(.reset)
        note = nil; chips = []; chipsError = nil; refineError = nil; costText = nil
    }
}
```

```swift
import CryptoKit
import Foundation
import Observation
import SwiftData
import TranscriberCore
import UIKit

struct DecryptedNote {
    let raw: String?
    let cleaned: String?
    let readable: Bool
    let snapshot: NoteSnapshot
    var bestText: String { cleaned ?? raw ?? "" }
}

@MainActor @Observable
final class HistoryStore {
    let container: ModelContainer
    private(set) var hasUnreadable = false
    @ObservationIgnored private var queued: [NoteSnapshot] = []
    @ObservationIgnored private var cachedCipher: NoteCipher?
    private static let keyAccount = "history_key"

    init(container: ModelContainer) {
        self.container = container
        NotificationCenter.default.addObserver(forName: UIApplication.protectedDataDidBecomeAvailableNotification,
                                               object: nil, queue: .main) { [weak self] _ in
            MainActor.assumeIsolated { self?.flushQueued() }
        }
    }

    static func makeContainer() -> ModelContainer {
        let dir = URL.applicationSupportDirectory.appending(path: "History", directoryHint: .isDirectory)
        do {
            try FileManager.default.createDirectory(at: dir, withIntermediateDirectories: true,
                attributes: [.protectionKey: FileProtectionType.complete])
            var values = URLResourceValues(); values.isExcludedFromBackup = true
            var mutableDir = dir
            try mutableDir.setResourceValues(values)
            let config = ModelConfiguration(url: dir.appending(path: "History.store"))
            return try ModelContainer(for: Note.self, configurations: config)
        } catch {
            return try! ModelContainer(for: Note.self, configurations: ModelConfiguration(isStoredInMemoryOnly: true))
        }
    }

    /// nil while the phone is locked (the key is WhenUnlockedThisDeviceOnly).
    private func cipher() -> NoteCipher? {
        if let cachedCipher { return cachedCipher }
        switch Keychain.read(Self.keyAccount) {
        case .found(let data):
            cachedCipher = NoteCipher(key: SymmetricKey(data: data))
        case .notFound:
            let key = SymmetricKey(size: .bits256)
            guard Keychain.set(key.withUnsafeBytes { Data($0) }, for: Self.keyAccount) else { return nil }
            cachedCipher = NoteCipher(key: key)
        case .unavailable:
            return nil
        }
        return cachedCipher
    }

    func upsert(_ s: NoteSnapshot) {
        // The store is .complete and the key is WhenUnlocked: while locked, hold the write in memory.
        guard UIApplication.shared.isProtectedDataAvailable, let cipher = cipher() else {
            queued.removeAll { $0.id == s.id }
            queued.append(s)
            return
        }
        let context = container.mainContext
        let id = s.id
        let existing = try? context.fetch(FetchDescriptor<Note>(predicate: #Predicate { $0.id == id })).first
        let note = existing ?? Note(id: s.id, createdAt: s.createdAt, status: s.status.rawValue)
        if existing == nil { context.insert(note) }
        note.status = s.status.rawValue
        note.language = s.language?.rawValue
        note.provider = s.provider?.rawValue
        note.model = s.model
        note.costUsd = s.costUsd
        note.pendingAudioFile = s.pendingAudioFile
        note.rawCipher = try? s.rawTranscript.map(cipher.seal)
        note.cleanedCipher = try? s.cleanedText.map(cipher.seal)
        try? context.save()
    }

    func flushQueued() {
        let pending = queued
        queued.removeAll()
        pending.forEach(upsert)
    }

    func text(of note: Note) -> DecryptedNote {
        let cipher = cipher()
        func open(_ data: Data?) -> (String?, Bool) {
            guard let data else { return (nil, true) }
            guard let cipher, let text = try? cipher.open(data) else { return (nil, false) }
            return (text, true)
        }
        let (raw, rawOK) = open(note.rawCipher)
        let (cleaned, cleanedOK) = open(note.cleanedCipher)
        let readable = rawOK && cleanedOK
        let snapshot = NoteSnapshot(id: note.id, createdAt: note.createdAt, rawTranscript: raw, cleanedText: cleaned,
                                    language: note.language.flatMap(Language.init(rawValue:)),
                                    provider: note.provider.flatMap(Provider.init(rawValue:)), model: note.model,
                                    costUsd: note.costUsd, status: NoteStatus(rawValue: note.status) ?? .done,
                                    pendingAudioFile: note.pendingAudioFile)
        return DecryptedNote(raw: raw, cleaned: cleaned, readable: readable, snapshot: snapshot)
    }

    // Kept out of text(of:): that runs inside view bodies, where mutating observed state loops.
    func refreshReadability() {
        let notes = (try? container.mainContext.fetch(FetchDescriptor<Note>())) ?? []
        hasUnreadable = notes.contains { !text(of: $0).readable }
    }

    func delete(_ note: Note) {
        if let file = note.pendingAudioFile { try? FileManager.default.removeItem(at: AudioFiles.url(named: file)) }
        container.mainContext.delete(note)
        try? container.mainContext.save()
    }

    func deleteAll() {
        let all = (try? container.mainContext.fetch(FetchDescriptor<Note>())) ?? []
        all.forEach(delete)
        hasUnreadable = false
    }

    func exportFile() throws -> URL {
        let notes = try container.mainContext.fetch(FetchDescriptor<Note>())
        let entries = notes.map(text(of:)).filter(\.readable).compactMap { d -> ExportEntry? in
            guard let raw = d.raw else { return nil }
            return ExportEntry(date: d.snapshot.createdAt, text: raw, cleaned: d.cleaned, language: d.snapshot.language,
                               provider: d.snapshot.provider, model: d.snapshot.model)
        }
        let stamp = Date.now.formatted(.iso8601.year().month().day())
        let url = FileManager.default.temporaryDirectory.appending(path: "transcriber-history-\(stamp).json")
        try HistoryExport.encode(entries).write(to: url, options: [.atomic, .completeFileProtection])
        return url
    }
}
```

```swift
import Foundation
import LocalAuthentication
import Observation
import TranscriberCore

@MainActor @Observable
final class HistoryLock {
    private(set) var isUnlocked = false
    private(set) var error: String?
    @ObservationIgnored private var backgroundedAt: Date?

    func unlock() async {
        let context = LAContext()
        do {
            isUnlocked = try await context.evaluatePolicy(.deviceOwnerAuthentication, localizedReason: "Unlock your note history")
            error = nil
        } catch {
            isUnlocked = false
            self.error = (error as? LAError)?.code == .userCancel ? nil : error.localizedDescription
        }
    }

    func lock() { isUnlocked = false }

    func didEnterBackground() { backgroundedAt = .now }

    func didBecomeActive() {
        if LockPolicy.shouldRelock(backgroundedAt: backgroundedAt, now: .now) { lock() }
        backgroundedAt = nil
    }
}
```
